# «Батин Суп»

Веб-платформа для поиска рецептов и заказа ингредиентов онлайн.

## Тип проекта
Веб-приложение (frontend + backend + база данных).

## Цель проекта
Создать удобный сайт, где пользователь может:

1. Найти рецепт по ингредиентам, кухне, калорийности и времени готовки.
2. Добавить рецепт в избранное.
3. Заказать ингредиенты из списка рецепта в интернет-магазине или партнёрской сети.
